📇 Rolodex CLI Application
A basic command-line contact management system built in C# using a local SQL Server database. This app allows users to view, add, delete, and (soon) update contact information — like a digital Rolodex!

🛠️ Tech Stack
Language: C#

Database: SQL Server (LocalDB)

Platform: Console (.NET)

🚀 Features
View all entries in the Rolodex

Add new contact entries

Delete existing entries (under development)

Update entries (placeholder for future)

Exit the application gracefully

📦 Project Structure
The core functionality is implemented in a simple while loop that continuously prompts the user for input until they choose to exit.

Menu Options
View Entries
Displays all saved Rolodex entries from the database.

Add New Entry
Prompts the user for contact details and stores them in the SQL Server database.

Delete Entry (Coming Soon)
Will allow deletion of entries by name (code placeholder included).

Update Entry (Coming Soon)
Placeholder for future update functionality.

Exit
Closes the application.
